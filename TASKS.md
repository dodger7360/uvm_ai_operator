## Definition of Done

Задача считается выполненной, если:

- [ ] код работает;
- [ ] бизнес-логика отделена от Telegram handlers;
- [ ] данные валидируются;
- [ ] AI не является источником истины;
- [ ] есть необходимые тесты;
- [ ] нет секретов в коде;
- [ ] изменение не ломает существующий функционал;
- [ ] результат проверен на реальном сценарии.
