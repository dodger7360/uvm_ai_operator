## 3. Найденные противоречия

Mac как обязательная разработка; заморозка всех будущих интеграций; узкая цель
форматирования; развёрнутая queue/typing описывались как неустановленные; старый
dispatch/прямая доставка — как production путь; ранние утверждения об отсутствии
живых испытаний. Корневые ADR предписывали AIService, а активный v2 его не вызывает.
Нынешний formatter всё ещё показывает версию и может объявлять отсутствие
уточнений без предметного доказательства. Последнее зафиксировано как дефект/цель,
а не выдано за исправление кода.

## 4. Утверждённые решения

Один UVM_Steel, только Steel Agent v2 / gpt-6-luna/high; GPT понимает предмет и
намерения, Python валидирует/считает/хранит. Windows, SQLite, Git/GitHub,
forward-only, прежний supervisor/Action/locks, один polling и до трёх execution
worker. Сохранение исходника/позиций/различий/истории, прав и offset; unknown без
автоматических повторов. Нет внешнего guard/ProgramData/admin, старого ИИ и
второго AI pipeline. Запрет экспорта production-строк сохраняется. Источники
решений и политика повторного доступа перечислены в DECISIONS.
