## Известные ошибки и ограничения

- Нормализация не принята как предметно надёжная: структурные отказы и неполное
  извлечение характеристик остаются. Покрытие символов не доказывает полноту товара.
- №21: ремонтный план отклонён по `duplicate_characteristic:i1`; первичный
  schema-отказ не локализован. Синтетический тест внедряет дубликат и проверяет
  отказ Python, а не исправление живой GPT.
- Для прежнего `empty_source_range:s2` есть безопасная обработка служебных пробельных
  records. Точный старый live payload неизвестен; проверки не ослаблены.
- `explanation` повторяет всю заявку. Обычный render выводит версию и может писать
  «Не требуется уточнений» по partial-флагу; профессиональная полнота не доказана.
- Многословность, лишние Markdown-символы и источники мешают копированию — замечания
  владельца; полные причины всех проявлений ещё не локализованы.
- Append отсутствует; clarify не должен подменять добавление созданием заявки.
  Сейчас одна активная заявка пользователя; возврат архивной как активной не готов.
- Excel/PDF/фото, склады, цены, поставщики, Bitrix24 и почта **к v2 не подключены**.
- Unknown требует ручного разбора, exactly-once внешних API не обещается.
  Переполнение первой очереди пользователя может задержать общий admission;
  длинный GPT способен превысить stop timeout без права принудительного kill.
- Forward-only; внешний guard и возврат старого обработчика не поддерживаются.
