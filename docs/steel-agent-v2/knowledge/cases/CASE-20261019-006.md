1. Разделительные запятые не нужны.
2. Пустые строки между товарными строками не нужны.
3. «12м» сохранять в метрах, не заменять на «L=12000 мм».
4. Удалить лишние слова вроде «квадратная», если форма очевидна из геометрии.
5. Нужен тоннаж, не метраж; использовать расчётную массу из проверенного сортамента.
6. Фасонный прокат рядом: сначала балки, затем швеллер; профильная труба отдельно.
7. В балках для коммерческой нормализации по пояснению владельца: Ст3 → С255; также дано соответствие 09Г2С → С355. Последнее в данном исходнике не использовалось (балка 60Б2 уже С355).

(936 м)», «Труба профильная 100×100×4 мм Ст3 12м — 50 шт. (600 м)». Задача: заменить только метраж в скобках на тоннаж, сохранив штуки.

## 6. Основания расчёта, ограничения и применимость

- Вес балки 25К1 (62,6 кг/м), 30Б1 (32,0 кг/м), 60Б2 (105,5 кг/м): [ГОСТ Р 57837-2017, таблица сортамента](https://metcalc.ru/calc-metalloprokat/steel/balka/table/standard-59), отдельно [60Б2](https://elsort.ru/?id=dvutavr%2F57837-2017%2F60b2).
- Швеллер 18П: 16,3 кг/м по [ГОСТ 8240-97](https://base.garant.ru/3924246/).
- Профильная труба 100×100×4: ≈11,73 кг/м по [справочной таблице с учётом закруглений](https://www.calcal.ru/ves-profilnoj-truby-100x100). Этот ориентир зависит от стандарта изготовления и допусков, фактическая масса не подтверждена.
- Никакие номера ГОСТ не были в исходной заявке, поэтому **в товарных строках** они не добавлены. Указанные здесь источники обосновывают расчётные коэффициенты, не утверждают требования заказчика по ГОСТ.
- Ст3 → С255 применено только к балке 30Б1 в этом кейсе по явному коммерческому пояснению владельца; не означает автоматическую нормативную взаимозаменяемость и не заменяет Ст3 у швеллера или трубы.
- Порядок «балки, затем швеллер» подтверждён для этого представления. BR-009 оставляет общий порядок видов нерегламентированным, поэтому не вводить глобальный приоритет категорий без отдельного утверждения.
- Позиции 5/2/3/4/1 учтены **по одному разу**, несмотря на перестановку. Общий тоннаж по умолчанию не выводить.
- Никакие изменения кода/production/Telegram этой публикацией не выполняются. Знания ещё не загружаются v2 автоматически.
