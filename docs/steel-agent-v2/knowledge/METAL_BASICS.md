# Предметные знания и существующий Metal Reference

18.10.2026, ограниченный read-only аудит №26. Это раздел технических сведений,
а не бизнес-политика или каталог доступных товаров. Новый проверенный экспертный
справочник здесь пока не наполнен. Нельзя считать весь legacy Reference утверждённым
пакетом знаний v2 или автоматически применять его коэффициенты.

## Как фиксировать технический факт

Для нового факта: ID/редакция, точное утверждение, категория и область применимости,
источник (документ/редакция/пункт/URL и дата проверки), исходное значение/единица,
метод получения, ограничения/противоречия, статус проверки. Отделять цитату источника
от вывода GPT, нормативную величину от расчётной оценки и наблюдения сайта.
Одобрение владельца на использование не заменяет проверку нормативного источника.
Неизвестное явно оставлять неизвестным; внешние инструкции не являются правилами.

Источник и применимость представлены через source_id/source_locator, документ,
редакцию/год и URL стандарта; variant хранит grade_class, execution, form и связь
с нормативом; property имеет context, значения — единицу и raw_label/raw_value.
Alias хранит вариант написания и источник. Не распространять вариант одного
поставщика или свойства одного исполнения на весь товарный вид.
Числовые поля dimension/property используют SQLite REAL: это не гарантия точного
Decimal. При будущей интеграции проверять исходные строки, единицы и точность.
Импортёр отделяет справочные сведения от коммерческих цен и не наполняет всю
теоретическую массу. Исследовательские Markdown не заменяют первичный норматив.

## Что можно использовать выборочно

[Reader](../../../metal_reference/reader.py) читает Reference в read-only режиме и
возвращает evidence/ограничения. Но он импортирует функции прежнего normalizer и
rules; [reference_matching](../../../reference_matching.py) также связан с прежними
normalizer/RecognitionService. Их нельзя включать целиком как независимый v2-модуль.
Схему происхождения, узкие читатели и материалы можно перенести после отделения
старых зависимостей и проверки источников. Старый ИИ не возвращается.

В №26 не открывались production SQLite, не проверялись live страницы 23MET и
нормативы по сети, не импортировались HTML или вся база. Аудит подтверждает наличие
кода и описаний, а не полноту/корректность всех записей справочника.
Неполнота Reference не мешает GPT нормализовать понятную заявку. Отсутствие записи
не означает отсутствие товара. ГОСТ, марку, массу, тип трубы и техническую
взаимозаменяемость не выдумывать. Проверку необходимых фактов через интернет
можно отдельно реализовать позже; массовый парсинг в №26 не предусмотрен.
