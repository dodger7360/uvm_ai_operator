# Итоги рабочей сессии 13.10.2026

## Исправление missing_positions

Опубликованный коммит: `56125ea232c129165902e7a4198fc794f7704ea8`
(`fix: preserve source position fidelity in Telegram normalization`).

Причина отказа: `TelegramService._build_active` требовал присутствия всей
исходной товарной строки внутри `source_text` извлечённой позиции. Корректный
товарный фрагмент без разговорного вводного слова или города мог вызвать
`missing_positions`, даже при совпадении числа исходных и извлечённых позиций.
Точные ответы модели для исходного отказа не сохранились; конкретные пропущенные
слова не установлены.

Исправление сопоставляет строки с отдельными извлечёнными позициями, допускает
заданные вводные слова и подтверждённый исходным текстом город в конце строки,
восстанавливает полную исходную строку перед проверкой атрибутов. Каждая строка
используется один раз: дубли требуют отдельных позиций. Проверки отклоняют
пропуски, лишние позиции, объединённые фрагменты и неподтверждённый город.
Сохранены проверки марок, ГОСТ/ТУ, размеров и точных Decimal-количеств.

## Доставка и текущие границы MVP

Рабочая схема: **Mac → GitHub main → Windows → Telegram**.
На Mac выполняются разработка и автоматические проверки. Проверенный код
публикуется в GitHub; на Windows запускается UVM_Steel в режиме polling.
По сообщению пользователя Windows обновлён до `56125ea`, бот работает.
Прямое управление Windows в сессию закрытия работ не входит.

Текущий интерфейс принимает текстовые заявки. Нормализация, уточнения и
структурированные корректировки реализованы, но пользовательскую приёмку
корректировок нужно продолжить отдельно. Вложения пока не поддерживаются.
Поиск остатков, рыночных предложений и полный закупочный процесс не подтверждены
этими двумя тестами нормализации.

Обработка сложной заявки на 21 позицию занимает **30–60 секунд по наблюдению
пользователя**. Это приблизительное время ответа, не статистический замер
и не измерение сетевой задержки или отдельных этапов. Настройки AI и
производительность при закрытии сессии не меняются.

Проверка города требует исходного фрагмента; географический справочник
не используется. Альтернативные написания и названия с цифрами могут
отклоняться консервативно.
