# Версия Telegram-бота

Команда `/version` отвечает: `UVM_Steel — версия 1.01`.
Доступна одобренным участникам, не вызывает AI и не расходует квоту.
Активная заявка и история не изменяются. Команда указана в `/help`.

Версия задаётся переменной окружения `APP_VERSION` при запуске/деплое.
Существующая загрузка `.env` также поддерживает `APP_VERSION=1.01`.
Если значение отсутствует или пустое, используется начальная версия `1.01`.
Номер хранится строкой: `1.01` не превращается в `1.1`.

Для следующего выпуска задайте новое значение APP_VERSION и штатно
перезапустите единственный Windows-экземпляр. Менять код команды не требуется.
При перемещении версии с Mac на Windows не копируйте целиком `.env`:
при необходимости меняется только APP_VERSION, остальные настройки сохраняются.

Команда показывает назначенный номер выпуска; актуальность относительно
GitHub она автоматически не проверяет. Для диагностики сохраняйте также SHA
установленного коммита в отчёте обновления.
